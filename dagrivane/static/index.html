    Execution contract
    
          
    
            Commands run locally without a shell. A failed prerequisite blocks
            dependent tasks. Successful checkpoints are retained for an
            unchanged run specification. An interrupted task with an unknown
            external outcome requires reconciliation.
          
    
          
    
            This workbench runs the bundled command and typed data pipelines. It
            does not accept arbitrary remote commands or perform a production
            release.
